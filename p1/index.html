提问

· 问到范围外，系统应该拒答而不是编。试试「今天北京天气怎么样」。
这一版把 Python 服务搬进了浏览器：同样的分词（英文词 + 汉字 bigram）、同样的 BM25 公式、同样的域闸门与抽取式回答。 因此无需服务器也能现场提问、跑 30 条评测；代价是没有“联网调用模型”的环节，延迟数字也只代表本机。

评测

覆盖范围

    评测定义：hit@3（正确文档是否进前 3）· 关键词覆盖（答案是否命中期望要点）· 拒答准确率（该拒的拒、不该拒的不拒）· P50/P95 延迟。
    生成层当前为抽取式（本机无可用 LLM）；接口已按「检索 → 上下文 → 生成」切开，换成任意 LLM 只需替换 answer() 的生成段。
    表里的“基线”是 Python 服务跑出的原始数字；在浏览器里点“跑 30 条评测”会用同一口径重算，延迟会明显更低（没有网络与进程开销）。
