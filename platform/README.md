# AI 产品经理 · 全链路工作台（v2）

一个**离线可用、零依赖**的求职训练系统：从「知识系统」到「项目工作台」，再到「评测实验室 → 求职管线 → 面试训练 → 复盘」，最后沉淀成证据卡与简历 bullet。

不需要安装、不需要联网、不需要账号。双击 `index.html` 即可（推荐 Edge / Chrome）。

> 知识源：亚慧《AI 产品经理（知识星球，持续更新……）》，约 46 万字。
> <https://my.feishu.cn/wiki/OY4FwGXr8i2diPkxkvEcNVA7nhg>
> 本平台**不复制原文**，只做章节索引、要点提炼与练习设计；每张卡都可跳回原文对照。

## 一、它解决什么问题

市面上的 AI PM 资料的问题是「读了很多，但拿不出东西」。这个工作台把链路倒过来：

```
知识（够用就好） → 项目（7 个阶段，过门制） → 评测（数字） → 证据卡（能讲） → 投递 → 面试 → 复盘
```

首页永远只回答一个问题：**下一步只做哪一件**。它由一条决策链算出：

1. 没做能力自评 → 先自评
2. 没选项目 → 选一个（别同时开三个）
3. 项目没走完 7 阶段 → 继续当前阶段
4. 本周没写证据卡 → 去写
5. 目标 JD 少于 3 个 → 补 JD
6. 没有投递记录 → 投第一份
7. 模拟面试少于 5 次 → 去练
8. 都齐了 → 复盘并更新简历

## 二、七个模块

| 模块 | 你得到什么 | 关键机制 |
|---|---|---|
| 总览 · 下一步 | 今天干什么 | 决策链 + 链路 6 项进度 + 能力雷达 |
| 8 周路径 | 每周学什么、交付什么 | 每周：3 个必读 / 1 个产出 / 1 条验收 / 1 个死亡点 |
| 知识系统 | 13 章地图 + 24 张卡 | 章节筛选、关键词搜索、只看未掌握、自测 + 掌握标记 |
| 项目工作台 | 3 个模板 + 7 阶段过门 | 每阶段有产出框与过门条件；未写产出不能进下一阶段 |
| 评测实验室 | 评测集、判定、跑分 | 样本判定（通过/不通过）、通过率、历史跑分 |
| 求职管线 | JD 差距、投递看板、bullet 库 | 8 个投递状态；按自评 6 维算差距；证据卡自动生成 bullet |

| 复盘 · 证据卡 | 六行证据 + 周复盘 | 假设/动作/数字/反证/结论/下周；导出 Markdown |
| 设置与数据 | 导入导出、清空 | localStorage，一键 JSON 备份 |

## 三、项目工作台的 7 个阶段（过门制）

1. **选题与用户**：目标用户、可证伪假设、明确不做什么
2. **范围与指标**：3 个指标 + 1 条失败线 + MVP 边界
3. **PRD 与评估**：3 页 PRD，含兜底、评估方案、上线监控
4. **数据与评测集**：≥30 条样本，≥8 条应拒答
5. **搭建与迭代**：可运行 demo + 3 成功 + 3 失败
6. **真人试用**：≥3 个真人用过，留原话
7. **复盘与叙事**：一页项目故事 + 可验证数字

三个项目模板：

- **P1 企业知识库问答（RAG + 评测）**：4–6 周，校招实习/转岗首选
- **P2 求职 JD 解析与匹配 Agent**：3–5 周，校招/社招都能讲
- **P3 AI 产品横评报告**：1–2 周，快速有公开作品

## 五、每周怎么用（5–10 小时）

- **周一 30 分钟**：看首页「下一步」，把本周产出改写成一句可验收的话。
- **周二–周四 4–6 小时**：只做产出；卡住回知识卡，不要再去搜新资料。
- **周五 2 小时**：找一个真人用一次，记录原话。
- **周日 60 分钟**：写证据卡 + 答 4 个复盘问题；没有数字就说明这周没进展。

## 六、验收标准

1. 你自己按 W1 跑一周，能产出一张**带数字**的证据卡；
2. 3 个同学 10 分钟内能各自选出「下一步做什么」；
3. 断网、换浏览器目录，双击仍能打开并读写本地数据；
4. 手机窄屏（≤820px）不横向滚动，主流程可走通。

## 七、边界与已知不足

- 知识卡 24 张，覆盖高频与易被追问点，不是全量；可按 `data.js` 的 `CARDS` 继续加。
- 题库没有录音与自动评分；建议手机录音，回听 90 秒版本。
- 评测实验室是**人工判定**，不接模型；它保证你有「尺子」，不保证自动跑分。
- 数据只在本地，不做多端同步；换设备前用「导出 JSON」。
- 原文更新后，以原文为准；本平台的提炼会过时。
